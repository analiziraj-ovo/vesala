# Вешала

Игра вешала на српској ћирилици, са речима за погађање у пет нивоа тежине (1 лако до 5 тешко).

- Тастатура на екрану са свих 30 слова азбуке. Може да се куца и на обичној тастатури, ћирилицом или латиницом.
- Што је тежи ниво, мање је дозвољених грешака (од 10 на нивоу 1 до 6 на нивоу 5).
- Картица „Админ“ приказује све речи са филтером по тежини и претрагом.

## Покретање

Отвори `index.html` у прегледачу. Није потребна инсталација.

## Речи

Речи се налазе у `words.json` (реч, појам као наговештај, тежина 1–5). Игра их учитава при сваком отварању. Ако фајл не може да се учита, користи почетни списак из `index.html` (`DEFAULT_WORDS`).

### Додавање речи преко админа

1. Направи GitHub кључ на https://github.com/settings/personal-access-tokens/new: Repository access → Only select repositories → `vesala`, а под Permissions → Contents изабери Read and write.
2. У игри отвори картицу „Админ“, налепи кључ и кликни „Сачувај кључ“. Кључ остаје само у том прегледачу.
3. Свака додата или обрисана реч чува се као нова измена (commit) у `words.json`. На GitHub Pages верзији се појављује за око минут.

Верзија на claude.ai чува речи у својој бази, без GitHub кључа.
